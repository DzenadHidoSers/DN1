# Šolski Dogodki (SERŠ Event Hub)

Spletna predstavitev skupinskega projekta: koledar šolskih dogodkov in prijave na delavnice.

Odprite `index.html` v brskalniku. Ilustracija persone je v `assets/persona-luka.png`.

## Predogled

Repozitorij priporoča razširitev **Live Server** za VS Code. Odprite index.html in izberite **Open with Live Server** oziroma kliknite **Go Live**. Za hiter lokalni predogled lahko uporabite tudi python -m http.server 8000 iz korenske mape repozitorija.
